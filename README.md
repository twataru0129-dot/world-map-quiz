# せかいの国 どこかな？（world-map-quiz）

世界地図から国をさがす、こどもむけの位置あてクイズです。
画面に出た国名（例：「日本をさがそう！」）を見て、地図をドラッグ・ズームしながら
その国を30秒以内にタップして答えます。サーバーやAPIキーは不要な、
GitHub Pagesでそのまま公開できる静的Webアプリです。

既存の「国旗クイズ」アプリとは完全に独立した別プロジェクトです。

## あそびかた

1. トップ画面で「あそびはじめる」を押す
2. ちいき（全世界／アジア／ヨーロッパ／アフリカ／北・中・南アメリカ／カリブ／オセアニア）を選ぶ
3. なんいど（かんたん／ふつう／むずかしい）を選ぶ
4. 出題された国を、地図をドラッグ・ピンチズームしながら30秒以内にタップする
   - 正解するまで／時間切れになるまで、何度でもタップできる
   - 間違えても地図の位置やズームは変わらない
5. 1ゲーム10問（対象国が10未満の組み合わせは自動的に問題数が減る）
6. 結果画面でスコア・平均回答時間・最大連続正解数を確認
7. 「コレクション」で正解したことのある国、「しょうごう」で獲得した称号を確認できる

正解済みの国・獲得した称号・ハイスコアは `localStorage` に保存され、
同じブラウザで次回も引き継がれます（ログイン不要）。

## ファイル構成

```
world-map-quiz/
  index.html              画面一式（トップ〜称号まで7画面）
  css/style.css            全体のスタイル（レスポンシブ・iPhone Safari対応）
  js/
    app.js                 画面遷移・ゲーム進行の統括
    countries.js           198の国・地域マスターデータ＋整合性チェック
    quiz.js                出題プール抽選・スコア計算などの純粋なゲームロジック
    gameMap.js              Leaflet地図の初期化、タップ／ドラッグ／ピンチの判定
    mapConfig.js            地域ごとの初期表示範囲・配色
    geoMapping.js           GeoJSON側コードとマスターデータの対応メモ
    storage.js              localStorage の読み書き
    sound.js                Web Audio API による効果音生成
    titles.js               称号の定義と判定
    utils.js                国旗絵文字などの小さなユーティリティ
    vendor/leaflet/         Leaflet本体をリポジトリに同梱（CDN依存なし）
  data/countries.geojson   198の国・地域だけに絞った簡略化済み世界地図データ
  assets/                  画像・音声素材用（現状は絵文字と合成音声のため未使用）
```

国データ・ゲームロジック・保存処理・UI処理をファイル単位で分離しているので、
難易度調整は `countries.js` の `difficulty` を書き換えるだけで完結します。

## マスターデータについて（重要）

添付PDF「世界の国旗198の国と地域 一覧」に掲載されている198件を、
そのままマスターデータとして採用しています（一般的な国一覧サイトは使用していません）。

- 日本語の国名・2文字コード・地域分類はPDFの表記をそのまま使用
  （例：ミャンマー(ビルマ)、コンゴ共和国(ブラザビル)、コンゴ民主共和国(キンシャサ) など）
- 地域分類は PDF どおり5分類（アジア48・ヨーロッパ46・アフリカ54・
  北・中・南アメリカ／カリブ36・オセアニア14＝合計198）。北米・南米は分割していません
- 台湾・コソボ・プエルトリコの「追加掲載」3件も収録
- アプリ内では国家承認等の政治的・法的な判断は行わず、学習用の一覧として扱っています

`js/countries.js` の `validateCountriesData()` が起動時に自動実行され、
地域別件数・合計198件・IDの重複がないことをチェックし、
問題があれば開発者コンソールに `console.error` を出力します。

## 地図データとコード対応

`data/countries.geojson` は Natural Earth（1:50m Admin 0 – Countries）を元に、
このアプリで使う198件だけを抽出・簡略化したものです（mapshaperで簡略化、約250KB）。

各フィーチャーの `properties.code` は基本的に ISO_A2 を採用していますが、
元データ側の値が特殊なものだけ ISO_A2_EH（拡張コード）を採用しています。
単純な名前一致ではなく、コード対応を優先して国データと地図を結び付けています。
詳細な対応表は `js/geoMapping.js` にコメントで残しています。

| 国・地域 | 備考 |
| --- | --- |
| 台湾 (TW) | 元データの ISO_A2 が `CN-TW` のため ISO_A2_EH の `TW` を採用 |
| コソボ (XK) | 元データの ISO_A2 が未設定のため ISO_A2_EH の `XK` を採用 |
| ノルウェー (NO) / フランス (FR) | 同上の理由で ISO_A2_EH を採用 |
| パレスチナ (PS) / プエルトリコ (PR) | 元データの ISO_A2 がそのまま一致 |
| オーストラリア (AU) | 本土＋海外領土など計3フィーチャーが同じ `code=AU` を持つため、まとめて「オーストラリア」として扱う |

## 難易度と mapPlayable

- `difficulty`（easy / normal / hard）は「その国が出題プールに加わる最小難易度」を表し、
  easy ⊂ normal ⊂ hard（上位の難易度は下位を含む）という累積方式です
- `mapPlayable: false` は、面積が非常に小さい・領土が海上に散らばっているなどの理由で
  スマートフォンでの正確なタップが難しい国・地域にだけ設定しています。
  マスターデータ・国名一覧・コレクションには通常どおり含まれ、**出題対象からのみ**除外されます

現在 `mapPlayable: false` にしている19件と理由:

| 地域 | 国・地域 | 理由 |
| --- | --- | --- |
| アジア | モルディブ | 環礁が広範囲に散在し、地図上の面積が極小 |
| ヨーロッパ | バチカン市国・モナコ・サンマリノ・リヒテンシュタイン | 国土面積が非常に小さいミニ国家 |
| アフリカ | カーボベルデ・コモロ・サントメ・プリンシペ・セーシェル | 島々が散在し、まとまった面積で表示できない |
| 北・中・南アメリカ／カリブ | アンティグア・バーブーダ・グレナダ・セントクリストファー・ネーヴィス・セントビンセント及びグレナディーン諸島 | 面積が非常に小さい、または島が散在 |
| オセアニア | キリバス・マーシャル諸島・ミクロネシア連邦・ナウル・トンガ・ツバル | 環礁国家で面積が極小、または広範囲に散在（キリバスは日付変更線をまたいで領土が分散） |

将来的には、十分なズームでの拡大表示や、小国専用の透明タップ領域などを用意して
`mapPlayable: true` に切り替えられる構造にしてあります。

## 効果音・保存

- 正解音／不正解音／時間切れ音はすべて Web Audio API でその場合成しており、外部音源ファイルは不要です
- iPhone Safari の自動再生制限に対応するため、「あそびはじめる」「なんいど選択」など
  ユーザー操作のタイミングで音声を有効化しています
- 音のON/OFFはトップ画面のボタンで切り替え可能（localStorageに保存）

## 地図操作とタップの誤判定防止（最重要ポイント）

指1本のドラッグでの地図移動、2本指でのピンチズーム、マウスドラッグ・ホイールズームに対応しています。
「地図を動かした操作」と「国をタップして回答した操作」を明確に区別するため、以下のガードを実装しています。

- タップ開始位置から一定距離（10px）以上ポインターが動いた場合は回答タップとして扱わない
- 地図のドラッグ（`dragstart`〜`dragend`直後）・ズーム（`zoomstart`〜`zoomend`直後）の間とその直後は
  クリック判定を無効化する
- 出題開始時の自動視点調整はアニメーションさせず即座に反映することで、
  アニメーション中の誤ガードでプレイヤーの最初のタップが無視されてしまう問題を防止

Playwright（Chromium）による自動テストで、ドラッグ操作・ホイールズーム・2本指ピンチ操作の
いずれも回答として誤判定されないこと、また実際のタップは正しく判定されることを確認済みです。

## ローカルでの動作確認

ES Modules と `fetch` を使用しているため、`file://` では動作しません。
簡易HTTPサーバーを立てて確認してください。

```bash
cd world-map-quiz
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## GitHub Pages での公開手順

1. このリポジトリ（`world-map-quiz`）をGitHubにpush
2. リポジトリの Settings → Pages を開く
3. Source を「Deploy from a branch」、Branch を公開したいブランチ（例: `main`）とルート（`/`）に設定
4. 数分後に `https://<ユーザー名>.github.io/world-map-quiz/` で公開される

相対パスのみを使用しており、サーバーサイド処理・ビルド工程は不要です。
